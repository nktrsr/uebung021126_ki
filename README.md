# uebung021126_ki

Erkenntnisse aus der heutigen Veranstaltung:
- Die KI erleichtert die Arbeit mit großen Datensätzen enorm; Sie muss aber trotz dessen kritisch hinterfragt werden. Teilweise waren Ausarbeitungen etwas unvollständig und mussten durch eine weitere Nachfrage erweitert werden.
- Auch das visualisieren der Messwerte mit Diagrammen schafft die KI gut. Verschiedenste Diagrammtypen erstellt die KI recht zuverlässig.
- Das Erstellen von Datenanalyse-Modellen durch die KI liefert gute Progrnose werte, allerdings waren Vorgehensweisen teilweise etwas dünn beschrieben und haben Nachfragen benötigt.
